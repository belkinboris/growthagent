# Аналитик Воронки — правила репозитория

## Что это

Платформа, которая подключается к digital-продукту по HTTP и отвечает владельцу:
что происходит, где теряются люди, что делать дальше. Первый подключённый
продукт — АвтоПост (projectautopost.ru). Цели и бэклог — `PRODUCT_ROADMAP.md`,
принципы продукта — там же (нарушать нельзя).

## Структура

- `app/main.py` — FastAPI: `/health`, `/status`, Telegram webhook, монтирование
  платформы под `/growth`, запуск планировщика в startup.
- `app/platform_api.py` — всё API веб-платформы (`/growth/api/*`).
- `app/platform_auth.py` — вход, HMAC-сессии. Личность внутри подписанного
  токена: `<срок>:u<id>` — аккаунт, `<срок>` без `:u` — владелец по паролю
  из окружения.
- `app/accounts.py` — пароли, регистрация, владение проектами
  (`PlatformUser`, `ProjectMember`).
- `app/static/platform/index.html` — весь интерфейс: один файл, ванильный JS,
  без сборщика. Тема одна (тёмная), цвета серий валидированы под тёмную
  поверхность.
- `app/scheduler.py` — цикл сбора: коннекторы → нормализация → снэпшоты →
  правила → алерты. Единственное место, где все источники встречаются вместе.
- `app/connectors/` — адаптеры источников. Всё, что специфично для конкретного
  продукта, живёт только здесь.
- `app/rules.py`, `analyzer.py`, `confidence.py` — детерминированные правила.
  **LLM в цикле анализа не участвует.**
- `app/growth_loop.py` — рекомендация → эксперимент → вердикт.
- `app/commercial_report.py`, `owner_report.py` — тексты отчётов. Формулировки
  выверены (честность про малые выборки) — переписывать только осознанно.
- `app/ask.py` — разговорный слой (Yandex LLM), только по явному вопросу владельца.

Корень репозитория очищен 27.07.2026 (задача C3): 41 повреждённый дубликат
удалён, три потерянных при той загрузке исправления восстановлены (защита от
OOM в `connectors/direct.py`, диагностика памяти в `scheduler.py`, endpoint
`/api/memory`). Рабочий код только в `app/`; примеры endpoint'ов для стороны
продукта — в `examples/`.

## Как запускать и проверять

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8080   # прод-команда (Timeweb)
python3 -m pytest tests/ -q                        # 708 тестов, все зелёные
```

Прогон должен быть чистым. Любое падение — регрессия, а не «известная
проблема»: три теста с захардкоженным путём исправлены 27.07.2026 (C2).

Локальная проверка интерфейса:

```bash
PLATFORM_ADMIN_PASSWORD=t PLATFORM_COOKIE_SECURE=false \
  DATABASE_URL=sqlite:///./local.db python3 -m uvicorn app.main:app --port 8321
```

Скриншоты — Playwright с предустановленным браузером:
`executable_path="/opt/pw-browsers/chromium-1194/chrome-linux/chrome"`.

## Соглашения

- Язык интерфейса, отчётов и комментариев — русский. Простой, без жаргона:
  «цена регистрации», а не «CPA-метрика».
- Комментарии объясняют **почему**, а не что. Особенно там, где решение
  выглядит странным (пример: счётчик-трещотка в `GrowthExperiment.peak_json`).
- Новая логика — через новые таблицы, `create_all()`, без `ALTER TABLE`
  на существующих (правило пришло из прод-инцидентов).
- Не ломать формулировки отчётов ради краткости: честность про выборку —
  часть продукта.
- Изменения проверять: тесты + скриншот экрана, который трогал.

## Ветка и деплой

Работа идёт в ветке `claude/funnel-analytics-migration-jgztix`, прод
разворачивается из `main` вручную (автодеплой Timeweb ненадёжен —
проверять хэш коммита). Метка сборки `BUILD_MARKER` в `app/config.py`
видна на экране обзора: по ней проверяют, что задеплоился новый код.

## Переменные окружения

Полный список — `.env.example`. Критичные: `DATABASE_URL`,
`PLATFORM_ADMIN_PASSWORD`, `PLATFORM_SECRET_KEY`, `LLM_PROVIDER=yandex`,
`YANDEX_API_KEY`, `YANDEX_FOLDER_ID`. Проект можно не задавать через env
вовсе — он подключается через мастер на `/growth`.
